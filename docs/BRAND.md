# Fraude brand assets

Anthropic / Claude–soft visual system: warm charcoal, cream type, terracotta accent.

## Files

| Path | Format | Size intent |
|------|--------|-------------|
| `assets/fraude-mark.svg` | SVG | 256×256 mark — avatars, favicons |
| `assets/fraude-banner.svg` | SVG | Wide wordmark |
| `assets/fraude-readme-hero.svg` | SVG | Hero: “Not Claude. FRAUDE.” |
| `assets/fraude-readme-hero.jpg` | JPG | Same hero, for social upload |
| `assets/fraude-banner.jpg` | JPG | Older raster banner (optional) |

## Colors

| Role | Hex |
|------|-----|
| Background | `#141413` / warm charcoal |
| Cream type | `#faf9f5` / `#f5f0e8` |
| Accent | `#d97757` / terracotta |
| Muted | `#b0aea5` |

Fonts: Poppins (UI), Lora / Georgia (editorial).

## Usage

1. **README** — centered hero at top (`width="720"`).
2. **LinkedIn / X** — upload JPG, not SVG.
3. **GitHub social preview** — Settings → Social preview → JPG.
4. **Favicon** — export PNG from `fraude-mark.svg` at 32 / 180 / 512 px if needed.

Do not stretch the mark; keep padding around the “F”.
